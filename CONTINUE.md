## Completed (что сделано и работает)
- `js/core/RNG.js` — seeded LCG RNG, сериализация состояния. Math.random() в симуляции НЕ используется.
- `js/core/TimeSystem.js` — минуты, календарь 12×30, скорости 1/5/20/100x, граница мира 1500 год.
- `js/core/SaveSystem.js` — слоты localStorage, экспорт/импорт JSON.
- `js/core/GameEngine.js` — цикл (1 тик = 1 минута), генерация мира (канон AoT + ~55 жителей + семьи), действия игрока, наследование после смерти игрока, fromSaveData.
- `js/world/World.js` — иерархия World→Region→District→Street→Building→Floor→Room, постоянные ID, BFS pathfinding, запертые двери блокируют путь, объекты с постоянным состоянием.
- `js/actors/NPC.js` — личность (5 черт), цели/страхи/желания, память (забывание лёгких), отношения (trust/affection/respect + label), семья, жизненные стадии, канонические персонажи (Эрен, Микаса, Армин, Леви, Ханджи, Жан, Саша, Конни, Шадис, Марко, Томас) со стартовыми связями.
- `js/simulation/Systems.js`:
  - ScheduleSystem — суточное расписание, перемещение по маршрутам;
  - EconomySystem — бизнесы (пекарня/таверна/лавка), товары, динамические цены, зарплаты, налоги, банкротства, наследство;
  - RumorSystem — слухи (source/time/reliability/content/truth), деградация при пересказе, ложные слухи;
  - DeathSystem — старение, болезни, смерть (постоянна), могилы на кладбище, наследство, горе родственников;
  - CrimeSystem — кражи → расследование → свидетели (ошибаются) → арест → СИЗО → суд → тюрьма → освобождение; коррупция и судебные ошибки;
  - EventSystem — социальные часы, свадьбы (только при высокой взаимной симпатии), рождения, редкая тревога титанов по seed.
- `js/ai/DialogueSystem.js` — приветствия по настроению, слухи игроку, мнения о персонажах (из памяти), комплимент/оскорбление, предложение брака.
- `js/ui/UI.js` + `js/main.js` + `css/main.css` + `index.html` — трёхпанельный UI (карта/сцена/игрок + журнал), диалоговое окно, стартовый экран с seed, кнопки скорости, мобильная адаптация.
- `test/smoke.js` — 23 автотеста, все зелёные (node test/smoke.js).

## Known limitations (честно: что НЕ реализовано)
- Уровни симуляции Near/Mid/Far: задуманы, но все NPC симулируются полностью (для ~60 NPC это нормально; для тысяч потребуется агрегация — NEXT TASK).
- Карьерный рост (повышения/увольнения/пенсии) — частично: есть банкротства и потеря работы, но нет повышений по rank.
- Смена поколений/строительство/разрушение городов на горизонте до 1500 года — не реализовано (мир живёт, но география статична).
- Изображения локаций: архитектура привязки готова (location.image), сами изображения пользователь создаст через Nano Banana.
- Внешняя AI-модель диалогов не подключена (диалоги шаблонно-контекстные). Точка интеграции: DialogueSystem возвращает {text,...}; внешняя AI должна лишь предлагать {dialogue, intent, emotion, possible_action}, решение — за GameEngine.
- Работа игрока-следователя (получать дела, допрашивать) — не реализована как игровая механика (система дел работает автономно).
- Слухи: нет автоочистки старых слухов (counter растёт; при долгой игре добавить pruning).

## Dependencies between files
Порядок загрузки (index.html): RNG → TimeSystem → SaveSystem → World → NPC → Systems → DialogueSystem → GameEngine → UI → main.
Все классы — в глобальном namespace `window.AOT`. НЕ переименовывать namespace.
GameEngine зависит от всех систем; Systems получают engine в конструкторе.

## Rules for continuation

- Сохранять совместимость save/load: при добавлении полей — добавлять их в serialize()/deserialize() со значениями по умолчанию.
- После изменений прогонять `node test/smoke.js`.
