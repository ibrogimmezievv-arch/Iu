# Attack on Titan — Living World Simulation

Браузерная игра-симуляция живого мира по мотивам Attack on Titan.
Район Трост, Стена Мария, 845 год. Мир живёт сам по себе: NPC работают,
женятся, рожают детей, болеют, умирают, торгуют, совершают преступления,
распространяют слухи — независимо от игрока.

## Как запустить

1. Распакуйте архив.
2. Откройте `index.html` в любом современном браузере
   (Chrome, Firefox, Edge, Safari). Сервер не нужен — проект без сборки.
3. Введите имя персонажа, выберите seed мира и нажмите «Начать новую игру».

Один и тот же seed всегда создаёт один и тот же мир. Другой seed — другой мир
(альтернативная история).

## Как работает симуляция

- Минимальная единица времени — **минута**. 1 реальная секунда = 10 игровых
  минут на скорости 1x. Ускорение (5/20/100x) — это больше тиков симуляции,
  а не «скип времени».
- Каждый час: NPC получают цель по расписанию (сон → завтрак → работа →
  рынок/таверна → дом), растут голод/усталость, происходят социальные
  взаимодействия (разговоры, обмен слухами, развитие отношений).
- Каждый день (06:00): производство товаров, старение и болезни, покупка еды,
  продвижение уголовных дел, рождения, случайные преступления.
- Каждый месяц (1-е число): зарплаты, налоги, банкротства.
- NPC перемещаются по графу локаций через BFS-маршруты — не телепортируются.
- Все случайные решения идут через единый seeded RNG; `Math.random()` в
  симуляции не используется. Состояние RNG сохраняется в сейв, поэтому после
  загрузки мир развивается детерминированно дальше.

## Как добавить NPC

```js
const npc = AOT.generateRandomNPC(engine.rng, engine.time.totalDays, {
  homeId: 'trost_home_02_room', locationId: 'trost_home_02_room', age: 30
});
npc.job = { title: 'кузнец', businessId: null, locationId: 'trost_market', salary: 22, rank: 1 };
engine.npcs.push(npc);
```

Канонический персонаж — добавьте запись в `canonicalNPCs()` в `js/actors/NPC.js`.

## Как добавить локацию

```js
const loc = engine.world.addLocation(new AOT.Location('trost_forge', 'Кузница', 'building', 'trost_market_street'));
engine.world.link('trost_market_street', 'trost_forge');
```

ID локации постоянен и уникален. Локация сериализуется автоматически.

## Как добавить изображение

Изображения привязываются к ID локации и **не генерируются заново**:

```js
engine.world.get('trost_market').image = 'assets/locations/trost_market.jpg';
```

Положите файл в `assets/locations/` и установите свойство `image` один раз —
оно сохранится в сейве.

## Как добавить событие

В `EventSystem` (js/simulation/Systems.js) добавьте метод и вызывайте его из
`socialHour()` (ежечасно) или `maybeWorldEvent()` (редкие мировые события).
Логируйте через `engine.logEvent('текст')`.

## Как изменить скорость

Кнопки 1x/5x/20x/100x в шапке или `engine.time.setSpeed(20)`.
Базовый темп: `MINUTES_PER_REAL_SECOND` в `js/main.js`.

## Как работает save/load

- Кнопка «Сохранить» пишет полный снапшот в слот `autosave` (localStorage).
- Сохраняется всё: seed, состояние RNG, время, игрок, все NPC (отношения,
  память, семьи, смерти), экономика, бизнесы, здания, объекты и двери,
  преступления и дела, слухи, события, журнал.
- Загрузка — со стартового экрана (список слотов).
- Проверка целостности: `node test/smoke.js` прогоняет полный цикл
  SAVE → LOAD → продолжение симуляции и сверяет детерминизм.
